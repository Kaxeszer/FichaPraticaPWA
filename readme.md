# Ficha Prática de Programação Web Avançada

Repositório destinado à realização da ficha prática da Unidade Curricular de **Programação Web Avançada**, integrada no **Mestrado em Engenharia Informática e Tecnologia Web (UTAD/UAb)**, no ano letivo **2026/2027**.

## Objetivos

- Familiarização com o Git e o GitHub.
- Gestão de versões e histórico de alterações.
- Utilização de commits e sincronização com repositórios remotos.
- Criação e formatação de documentos HTML.

## Tecnologias e Ferramentas

- HTML5
- Git e GitHub
- WebStorm (JetBrains)
